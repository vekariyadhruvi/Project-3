# Student Data Organizer

## Overview
The Student Data Organizer is a simple Python console-based application used to manage student records. It allows users to add, view, update, and delete student details, along with maintaining a list of subjects offered.

## Features
- Add new student details  
- Display all student records  
- Update existing student information  
- Delete student records  
- Display all subjects offered  
- Menu-driven interface  

## Technologies Used
- Python  
- Data Structures:
  - List  
  - Dictionary  
  - Set  
  - Tuple  

## How It Works
1. Run the Python script  
2. Choose an option from the menu:
   - 1 → Add Student  
   - 2 → Display All Students  
   - 3 → Update Student Information  
   - 4 → Delete Student  
   - 5 → Display Subjects Offered  
   - 6 → Exit  
3. Enter the required inputs as prompted  

## Example Input
```
Enter your choice: 1
Student ID: 101
Name: Dhruvi
Age: 20
Grade: A
Date of Birth: 01-01-2005
Subjects: Math, Physics, Python
```

## Notes
- Student ID should be unique  
- Subjects must be entered as comma-separated values  
- Proper input types should be provided (e.g., integers for age and ID)
